## 🚀 Task 1 — DSP Studio Pro

DSP Studio Pro is a Streamlit-based application for loading, visualizing, and processing digital signals through a graphical user interface.

### Features

* Load and visualize signals.
* Perform signal addition.
* Multiply a signal by a constant.
* Download processed signal results.
* Use an interactive web-based interface.

### 🛠️ Technologies

* Python
* Streamlit
* Matplotlib

### ▶️ How to Run

**1. Clone the repository**

```bash
git clone https://github.com/mohamedwalidhegab12-dev/Digital-Signal-Processing.git
cd Digital-Signal-Processing
```

**2. Install the dependencies**

```bash
pip install -r Task-1/requirements.txt
```

**3. Run the application**

```bash
streamlit run Task-1/app.py
```
